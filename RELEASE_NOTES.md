TerraRoad 0.8.0-dev — development preview for IngeTrazo 0.5.9.

Includes centerline/face road tools, junctions and roundabouts, editable parts,
curbs, sidewalks, lighting/signals, markings, map references and quantity export.
This release fixes map texture orientation and crop georeferencing, removes
unrequested splitter islands and improves painted-curb visibility.

Validation: 69 automated port tests; native viewport checks of a roundabout and
an asymmetric map/trace alignment fixture. Catalog package extraction and entry
point are validated separately. Full SketchUp feature parity is incomplete.
Automatic tracing uses OSM data rather than image recognition.
